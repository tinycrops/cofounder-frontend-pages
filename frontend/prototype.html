What this demonstrates

A prototype of the system, not just a page about the system.

Tiny domain model

Here it is a transparent keyword scorer, but the interface is built so a compact trained model could replace it later without changing the shell.

Visible policy graph

The graph is not hidden. You can see exactly which route was taken, why escalation occurred, and which actions are allowed.

Compiled shell behavior

The output is deliberately constrained into a narrow artifact: route, risk tier, approved actions, blocked actions, and an audit trail.
